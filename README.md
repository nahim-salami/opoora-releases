# Opoora — Téléchargements officiels

Applications mobiles **Opoora** — la livraison simple et suivie en temps réel au Bénin.

| Application | Fichier | Pour qui |
|---|---|---|
| 📦 **Opoora Client** | `opoora-client-vX.Y.Z.apk` | Commander une livraison et suivre son colis en direct |
| 🛵 **Opoora Livreur** | `opoora-courier-vX.Y.Z.apk` | Recevoir des missions, naviguer, valider les livraisons |
| 🏢 **Opoora Business** | `opoora-business-vX.Y.Z.apk` | Piloter sa flotte, assigner les courses, suivre les revenus |

➡️ **[Télécharger la dernière version](../../releases/latest)**

## Installation (Android)

1. Téléchargez le fichier `.apk` correspondant à votre usage.
2. Ouvrez-le — autorisez l'installation depuis une source inconnue si demandé.
3. C'est tout. Connexion par Google ou code email, sans mot de passe.

## Transparence

- Ce dépôt ne contient **que les binaires** ; le code source d'Opoora est développé dans un dépôt privé.
- Chaque APK est construit publiquement par GitHub Actions dans ce dépôt (onglet *Actions*) : chaque release est traçable jusqu'à son build.
